# Aleslanik2 Nepomuk

## How do I install these formulae?

`brew install aleslanik2/nepomuk/<formula>`

Or `brew tap aleslanik2/nepomuk` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "aleslanik2/nepomuk"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
